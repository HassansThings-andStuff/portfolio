# Portfolio

Write-ups, screenshots and design decisions from my personal projects.

I'm a Master of Data Science student at Deakin University, coming to data
from a background in psychology. Each write-up covers the problem, what I
built, the key decisions I made and what I learned, because the thinking
behind a project says more than the code alone.

| Project | What it is | Tech | Status |
|---|---|---|---|
| Hassan's Fishing Estimator | Fishing-conditions estimator for Victorian waters that labels every input as forecast, calculated or estimated, and grades the published evidence behind each factor. [Live app](https://hassans-fishing-estimator.pages.dev/) | React, Vite, JavaScript, Leaflet, Recharts, Open-Meteo | Live (v0.4.1) |
| Project Tanuki Kaizen (TK) | Read-only ASX stock analysis dashboard. Scores technical indicators as discrete signals and shows where they contradict each other, rather than averaging the conflict away. Analysis only, with no trading. | Python, pandas, yfinance, ta, Plotly, Streamlit, pytest | In development (V1) |
| Project Mitsu (密) | Minimalist web app for career self-reflection, built around an original instrument that separates what draws you to work from how you like to engage with it. Ends with a written reflection rather than a score or type. | Web app (stack TBC) | Planning |

## How each write-up is laid out

- **Summary**, with a screenshot and a link to the live version if there is one
- **The problem** it set out to solve
- **What I built**
- **Tech** used
- **Key decisions**, and the reasons behind them
- **What I learned**
- **Context**: personal or university project, and how it was made

## About the code

The source code for these projects is kept private. This repo shows what I
built and how I thought about it, rather than the code itself. Where a
project was built with AI assistance, its write-up says so and explains how
the work was divided.
